fsm2hdl.common

This package bundles everything that the FSM-to-HDL generator needs to run and validate the finite-state-machines that it produces.

It includes:

  • Core data-model classes - fsm2hdl.common.models
  • Configuration parameters - fsm2hdl.common.parameters
  • Useful utilities -fsm2hdl.common.utils

147                    transition_id += 1
